# Hi, I'm Rio Kamran 👋

Online I go by **RioMax**. I build things for my own PC and homelab, then open-source the ones other people might want.

**More about me → [rio.riomax.com](https://rio.riomax.com/)**

## What I make
- **[rewind](https://github.com/Rio-Kamran/rewind)** — a homemade Medal: keeps the last 60 seconds of your monitor in memory, and Ctrl+Alt+P saves it as an MP4.
- **[taskbar-per-monitor](https://github.com/Rio-Kamran/taskbar-per-monitor)** — a tiny Windows tray app to choose which monitors show the taskbar. Free alternative to DisplayFusion's per-monitor taskbar.
- Homemade Windows tools for RGB lighting, a live task board, a voice assistant, and a desktop "dynamic island" — most of them living on my own machines for now.
